Versi online (hosting statis)
=============================
Cara publish: drag folder ini ke https://app.netlify.com/drop
atau upload ke GitHub Pages / Cloudflare Pages.

Tidak perlu start.bat atau server.ps1, cukup index.html dan config.js.
Fitur Cari butuh API key YouTube Data API v3 (tempel di tab Cari).

Pembaruan: kalau memutar video dari tab Cari, video berikutnya di daftar hasil
otomatis diputar setelah yang sekarang selesai (tanpa perlu masuk Antrean saya).
Tombol berikutnya/sebelumnya dan mode ulang semua juga mengikuti daftar hasil itu.
